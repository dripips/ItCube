# ItCube

Платформа для учебного центра: направления, группы, расписание, журнал — и
работы с кодом, которые проверяются сами.

Первая версия жила в 2023 году: процедурный PHP, два входа (отдельный для
преподавателя, отдельный для ученика), посещаемость парой «ученик и дата» без
группы и загрузка файлов с расширением из имени в раздаваемую папку. Эта версия
переписана с нуля на Laravel; из старой унаследована только предметная область.

## Что уже готово

- **Запуск кода на четырнадцати языках.** Python, JavaScript, TypeScript, PHP,
  C, C++, Java, C#, Go, Rust, Ruby, Паскаль, SQL и Bash.
- **Проверка по тест-кейсам.** У задачи несколько входов со своими ожидаемыми
  ответами и баллами. Часть кейсов скрытая: ученик видит только «сошёлся или
  нет», без входа и без ожидаемого ответа, иначе решение подгоняют под
  известный ответ вместо того, чтобы заставить его работать.
- **Схема данных целиком:** люди и роли, направления, предметы, группы,
  расписание, занятия, журнал, задачи с кодом, тесты, контрольные, файлы,
  новости.

## Чего ещё нет

Интерфейса. Есть слой данных, исполнение кода и проверка работ, покрытые
тестами; страницы, вход и оформление — следующий шаг.

## Как исполняется чужой код

Своей песочницы нет и не планируется: код уходит на [Wandbox](https://wandbox.org).
Это осознанный выбор — школьная платформа не должна держать у себя инфраструктуру
для запуска недоверенного кода, а Wandbox уже её держит.

Одна площадка вместо нескольких выбрана не ради простоты: Go Playground не
принимает stdin, а без него не собрать ни одного тест-кейса с входными данными.

Списки запрещённых конструкций в `CodeRunner` — не изоляция, а вежливость: они
отсекают явную дурь до сетевого запроса, чтобы ученик получил внятный ответ
вместо таймаута.

Кейсы уходят пачкой в параллель. Причина в измерении: пять кейсов на Go
последовательно занимают около полутора минут, потому что одна сборка на
площадке идёт примерно двадцать секунд.

## Запуск

Нужны PHP 8.3+, Composer и PostgreSQL.

```bash
git clone https://github.com/dripips/ItCube.git
cd ItCube
composer install
cp .env.example .env
php artisan key:generate
createdb itcube
php artisan migrate
php artisan serve
```

Ключей и учётных записей у сторонних сервисов не требуется: Wandbox работает без
регистрации.

## Тесты

```bash
php artisan test
```

Тесты не ходят в сеть: HTTP подменяется, поэтому набор не зависит от чужой
доступности.
